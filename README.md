# 🚀 LOL 优化启动器 · 告别团战掉帧

专为国服《英雄联盟》设计的启动优化工具。

通过抢先调起 **ACE 游戏内置版**反作弊组件，取代扫描频繁、资源占用高的系统默认版，从底层消除团战掉帧与卡顿。

---

## 🔑 核心原理：为什么能防掉帧？

国服环境下通常并存两个版本的 **AntiCheatExpert (ACE)**：

| 版本 | 位置 | 特点 |
| :--- | :--- | :--- |
| **ACE 1（系统默认版）** | `C:\Program Files\...` | 磁盘扫描频繁，团战时 CPU 占用飙升，是掉帧的主因 |
| **ACE 2（游戏内置版）** | `游戏目录\Game\...` | 性能开销更低，运行更稳定 |

**工具逻辑**：ACE 具有"同时只能运行一个实例"的特性。脚本抢先拉起 **ACE 2** 并持续保活，迫使游戏绑定更流畅的内置版本，从而显著提升 FPS 稳定性。

## 🛠️ 第一步：环境准备（仅需执行一次）

为确保脚本能正确识别路径并成功调起组件，请依次完成以下设置：

### 1. 下载

- [点击此处前往最新版本下载页](https://github.com/ityme/lol.launcher.iWonder/releases/latest)，下载后解压到任意目录。

### 2. 游戏目录重命名（解决中文路径乱码问题）

- 找到英雄联盟的安装目录，例如：`D:\Tencent\WeGameApps\英雄联盟`
- 将 **英雄联盟** 文件夹重命名为 `League of Legends`
- 重命名后路径示例：`D:\Tencent\WeGameApps\League of Legends`

### 3. 路径初始化

- 首次运行任意 `.bat` 启动文件，若脚本检测到路径未配置，会自动弹出引导提示
- 按提示粘贴**全英文游戏路径**并回车确认
- 脚本将自动校验路径完整性，校验通过后永久保存至 `config.json`

### 4. **使用技巧**(可选)

- 可为 `.bat` 文件创建快捷方式并自由摆放，实现更便捷的调用。

## ⏱️ 第三步：启动流程说明

双击运行后，关注控制台窗口的输出提示：

1. **[环境检查]** — 若出现黄色警告，说明存在残留的游戏或 ACE 进程，请先手动关闭后重试。
2. **[执行启动]** — 脚本自动拉起游戏内置的 ACE 2 反作弊组件。
3. **[正在引导]** — 出现此提示后，立即在 LOL 登录器中完成登录操作（输入账号 → 选择大区 → 进入游戏）。
4. **[启动成功]** — 进入游戏大厅后，脚本显示绿色提示并开始 3 秒倒计时。
5. **[自动退出]** — 倒计时结束，窗口自动关闭，脚本完全释放资源。尽情享受游戏吧！

## ⚠️ 常见问题 FAQ

| 问题 | 解决方案 |
| :--- | :--- |
| **会不会封号？** | **不会。** 脚本不读写任何游戏内存，仅调整了 `SGuard64.exe` 的启动顺序，属于纯净的环境引导行为，完全符合官方机制。 |
| **提示"[ENV ERROR]"** | 确认 `.bat` 文件是在完整的项目目录结构下运行的，不要单独复制启动文件。 |
| **提示"校验失败"** | 检查路径是否仍包含中文字符，或是否指向了正确的游戏根目录（应包含 `Game`、`Cross` 等子目录）。 |
| **提示"无法启动组件"** | 右键点击 `.bat` 文件，选择 **"以管理员身份运行"**。 |

# 🚀 LOL 一键启动增强工具 (iWonder)

这是一个专为国服《英雄联盟》设计的启动优化工具。

通过强制优先调用 **ACE (游戏内置版)** 反作弊组件，

替代扫描频繁、占用高的系统默认版，从底层解决团战掉帧与卡顿问题。

---

## 🧠 核心原理：为什么它能防掉帧？

国服环境下通常存在两个版本的 **AntiCheatExpert (ACE)**：
*   **ACE 1 (系统默认版)**：位于 `C:\Program Files`。扫描磁盘极其频繁，会导致团战时 CPU 占用飙升，造成剧烈掉帧。
*   **ACE 2 (游戏内置版)**：位于 `游戏目录\Game\...`。性能开销更小，运行更稳定。

**工具逻辑：** 利用 ACE 具有“唯一运行性”的特点，脚本抢先调起 **ACE 2** 并维持运行，强制游戏关联更流畅的版本，从而提升 FPS 稳定性。

## 🛠️ 第一步：环境配置 (仅需执行一次)

为确保脚本能 100% 识别路径并成功调起组件，请务必完成以下两项基础设置：

1.  **游戏目录更名 (解决中文乱码风险)**
    *   找到你的英雄联盟安装目录（例如：`D:\Tencent\WeGameApps\英雄联盟`）。
    *   将 `英雄联盟` 文件夹重命名为：`League of Legends`。
    *   *修改后的全路径应类似：`D:\Tencent\WeGameApps\League of Legends`*

2.  **填写路径配置文件**
    *   在文件夹中找到 `LOL_ROOT_PATH` 文件，右键选择“记事本”打开。
    *   将你修改后的**全英文游戏路径**粘贴进去（例如：`D:\Tencent\WeGameApps\League of Legends`）。
    *   **保存并关闭文件**。

---

## 🎮 第二步：一键引导启动

根据你的登录习惯，选择对应的入口，双击运行即可：

*   **方案 A：官方原生模式** 👉 双击 `lol-launcher-by-origin.bat`
    *(适用于直接弹出英雄联盟登录框，不经过 WeGame 的玩家)*
*   **方案 B：WeGame 模式** 👉 双击 `lol-launcher-by-wegame.bat`
    *(适用于习惯从 WeGame 选区、使用官方助手的玩家)*

---

## ⏱️ 第三步：自动化引导流程

双击运行后，你只需要观察黑色控制台窗口的提示：

1.  **[环境检查]**：若窗口提示黄色文字，说明有旧的游戏或 ACE 进程未关闭，请手动关闭它们。
2.  **[执行启动]**：脚本会自动闪现并启动 ACE 2 反作弊组件。
3.  **[正在引导]**：看到此提示后，请立即操作你的 LOL 登录器（输入账号密码、选择大区、点击进入游戏）。
    *   *注：脚本每 2 秒检查一次 ACE 状态，若登录太慢导致 ACE 自动关闭，脚本会自动补跳。*
4.  **[启动成功]**：一旦进入游戏大厅（LeagueClient.exe 运行），脚本会显示绿色文字并进入 3 秒倒计时。
5.  **[自动退出]**：倒计时结束，窗口会自动关闭。此时脚本完全释放资源，你可以开始畅玩游戏。

## ⚠️ 进阶 FAQ (常见问题)


| 问题场景 | 解决方案 |
| :--- | :--- |
| **运行后提示“无法启动组件”？** | 请右键点击 `.bat` 文件，选择 **“以管理员身份运行”**。 |
| **为什么一定要改英文名？** | 国服默认路径包含中文，在不同系统编码下极易产生乱码导致脚本失效。改为 `League of Legends` 是最稳妥的方案。 |
| **这个会封号吗？** | **完全不会。** 脚本不修改任何游戏内存数据和核心文件。它仅改变了 `SGuard64.exe` 的启动顺序，完全符合官方逻辑。 |

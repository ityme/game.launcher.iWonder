# 🚀 LOL 优化启动器 · 告别团战掉帧

专为国服《英雄联盟》设计的启动优化工具。

通过抢先调起 **ACE 游戏内置版**反作弊组件，取代扫描频繁、资源占用高的系统默认版，从底层消除团战掉帧与卡顿。

---

## 🔑 核心原理：为什么能防掉帧？

国服环境下通常并存两个版本的 **AntiCheatExpert (ACE)**：

| 版本 | 位置 | 特点 |
| :--- | :--- | :--- |
| **ACE 1（系统默认版）** | `C:\Program Files\...` | 磁盘扫描频繁，团战时 CPU 占用飙升，是掉帧的主因 |
| **ACE 2（游戏内置版）** | `游戏目录\Game\...` | 性能开销更低，运行更稳定 |

**工具逻辑**：ACE 具有"同时只能运行一个实例"的特性。脚本抢先拉起 **ACE 2** 并持续保活，迫使游戏绑定更流畅的内置版本，从而显著提升 FPS 稳定性。

## ⏱️ 第三步：启动流程说明

双击运行后，脚本将**自动完成所有操作**，关注控制台窗口的输出提示：

1. **[自动检测]** — 脚本自动扫描全盘，找到英雄联盟安装目录（以及 Akari 客户端路径，如使用 Akari 模式）。无需任何手动配置。
2. **[环境检查]** — 若出现黄色警告，说明存在残留的游戏或 ACE 进程，请先手动关闭后重试。
3. **[执行启动]** — 脚本自动拉起游戏内置的 ACE 2 反作弊组件。
4. **[正在引导]** — 出现此提示后，立即在 LOL 登录器中完成登录操作（输入账号 → 选择大区 → 进入游戏）。
5. **[启动成功]** — 进入游戏大厅后，脚本显示绿色提示并开始 3 秒倒计时。
6. **[自动退出]** — 倒计时结束，窗口自动关闭，脚本完全释放资源。尽情享受游戏吧！

## ⚠️ 常见问题 FAQ

| 问题 | 解决方案 |
| :--- | :--- |
| **会不会封号？** | **不会。** 脚本不读写任何游戏内存，仅调整了 `SGuard64.exe` 的启动顺序，属于纯净的环境引导行为，完全符合官方机制。 |
| **提示"[ENV ERROR]"** | 确认 `.bat` 文件是在完整的项目目录结构下运行的，不要单独复制启动文件。 |
| **提示"[检测失败]"** | 脚本未能自动找到游戏目录，会转为手动输入模式。按提示粘贴正确的游戏根目录路径（应包含 `Game`、`Cross`、`Launcher`、`LeagueClient` 子目录）并回车确认即可。 |
| **提示"无法启动组件"** | 右键点击 `.bat` 文件，选择 **"以管理员身份运行"**。 |

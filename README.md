# 🚀 LOL 优化启动器(降掉帧)

这是一个专为国服《英雄联盟》设计的启动优化工具。通过强制优先调用 **ACE (游戏内置版)** 反作弊组件，替代扫描频繁、占用高的系统默认版，从底层解决团战掉帧与卡顿问题。

---

## 🧠 核心原理：为什么它能防掉帧？

国服环境下通常存在两个版本的 **AntiCheatExpert (ACE)**：

1.  **ACE 1 (系统默认版)**：位于 `C:\Program Files`。扫描磁盘极其频繁，会导致团战时 CPU 占用飙升，造成剧烈掉帧。
2.  **ACE 2 (游戏内置版)**：位于 `游戏目录\Game\...`。性能开销更小，运行更稳定。

**工具逻辑**：利用 ACE 具有“唯一运行性”的特点，脚本抢先调起 **ACE 2** 并维持运行，强制游戏关联更流畅的版本，从而提升 FPS 稳定性。

## 🛠️ 第一步：环境准备 (仅需执行一次)

为确保脚本能 100% 识别路径并成功调起组件，请务必完成以下基础设置：

### 1. 游戏目录更名 (解决中文乱码与路径识别风险)
*   找到你的英雄联盟安装目录（例如：`D:\Tencent\WeGameApps\英雄联盟`）。
*   将 **英雄联盟** 文件夹重命名为：**League of Legends**。
*   修改后的全路径应类似：`D:\Tencent\WeGameApps\League of Legends`

### 2. 路径初始化配置
*   首次运行任意 `.bat` 启动文件，脚本若检测到路径缺失，将弹出配置引导。
*   根据提示将你修改后的**全英文游戏路径**粘贴进去并回车即可。
*   脚本会自动校验路径完整性，校验通过后将永久保存。

## 🎮 第二步：一键引导启动

根据你的登录习惯，选择对应的入口，双击运行即可：

*   **方案 A：官方原生模式** 👉 双击 `lol-launcher-by-origin.bat`
    *(适用于直接弹出英雄联盟登录框，不经过 WeGame 的玩家)*
*   **方案 B：WeGame 模式** 👉 双击 `lol-launcher-by-wegame.bat`
    *(适用于习惯从 WeGame 选区、使用官方助手的玩家)*
*   **方案 C：Akari 模式** 👉 双击 `lol-launcher-by-akari.bat`
    *(适用于使用 Akari 客户端的玩家，提供更轻量化的启动体验)*

## ⏱️ 第三步：自动化引导流程

双击运行后，你只需要观察控制台窗口的提示：

1.  **[环境检查]**：若提示黄色文字，说明有旧的游戏或 ACE 进程未关闭，请先手动关闭它们。
2.  **[执行启动]**：脚本会自动调起游戏内置的 ACE 2 反作弊组件。
3.  **[正在引导]**：看到此提示后，请立即操作你的 LOL 登录器（输入账号、选择大区、点击进入游戏）。
    *注：脚本会实时监控 ACE 状态，若由于登录过慢导致 ACE 自动关闭，脚本会自动补跳。*
4.  **[启动成功]**：一旦进入游戏大厅，脚本会显示绿色文字并进入 3 秒倒计时。
5.  **[自动退出]**：倒计时结束，窗口自动关闭。此时脚本已完全释放资源，你可以开始畅玩游戏。
